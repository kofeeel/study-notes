# 08. 트리·그래프 기초 (카드 보기 전 1화면)

[← 목차](README.md)

## 목표
- 트리·그래프 용어를 헷갈리지 않고 말한다.
- "어떤 자료구조로 풀겠냐"에 트리/그래프 중 뭘, 왜 고르는지 답한다.
- BFS/DFS를 손으로 시뮬레이션할 수 있다.

## 핵심 1 — 용어

| 용어 | 뜻 | 한 줄 기억 |
|---|---|---|
| 그래프 | 정점(V) + 간선(E) | 관계를 표현. 방향/무방향, 가중치 유무 |
| 트리 | 사이클 없고 연결된 그래프. 간선 = V-1 | 계층 구조. 루트·부모·자식·리프 |
| 이진 트리 | 자식 최대 2개 | 완전 이진 트리 = 배열로 표현 가능(힙) |
| BST | 왼쪽 < 루트 < 오른쪽 | 탐색 O(log n), 치우치면 O(n) → RB트리 |
| 힙 | 부모 ≥(≤) 자식, 완전 이진 | 최댓값만 빠르게. 정렬은 아님 |
| 차수 / 깊이 / 높이 | 간선 수 / 루트→노드 거리 / 노드→가장 먼 리프 | 높이 h 균형 트리 노드 수 ≈ 2^h |
| DAG | 방향 있고 사이클 없음 | 의존성·빌드 순서 → 위상 정렬 |

## 핵심 2 — 표현

| 구조 | 코드 | 언제 |
|---|---|---|
| 트리 (포인터) | `struct Node{ int v; Node* l; Node* r; };` | BST, 씬 그래프 |
| 트리 (배열) | 자식 `2i+1, 2i+2`, 부모 `(i-1)/2` | 힙 |
| 그래프 인접 리스트 | `vector<vector<int>> adj(V);` `adj[u].push_back(v);` | 희소 그래프. 기본값 |
| 그래프 인접 행렬 | `bool m[V][V];` | 밀집 그래프, 간선 유무 O(1) |
| 그리드 | 2차원 배열 + `dx/dy` 4방향 | 맵 문제. 칸 = 정점, 인접 칸 = 간선 |

## 핵심 3 — 순회·탐색

| 알고리즘 | 도구 | 순서 | 쓰임 | 복잡도 |
|---|---|---|---|---|
| 전위 | 재귀 | 루트→좌→우 | 복사·직렬화, 씬 그래프 행렬 전파 | O(n) |
| 중위 | 재귀 | 좌→루트→우 | BST 정렬 순 출력 | O(n) |
| 후위 | 재귀 | 좌→우→루트 | 삭제, 수식 계산 | O(n) |
| BFS | 큐 + visited | 가까운 순 | 가중치 없는 최단거리, 레벨 | O(V+E) |
| DFS | 재귀/스택 + visited | 한 갈래 끝까지 | 경로 존재, 사이클, 백트래킹, 위상정렬 | O(V+E) |
| 다익스트라 | 최소힙 + dist | 거리 짧은 순 확정 | 양수 가중치 최단경로 | O(E log V) |
| A* | 최소힙, f=g+h | 목표 방향 우선 | 게임 길찾기 | 휴리스틱 의존 |

```cpp
// BFS 뼈대 — 이 6줄이 전부
queue<int> q; vector<int> dist(V, -1);
q.push(s); dist[s] = 0;
while (!q.empty()) {
    int u = q.front(); q.pop();                       // pop 잊으면 무한루프
    for (int v : adj[u]) if (dist[v] == -1) {        // 미방문만
        dist[v] = dist[u] + 1; q.push(v); } }        // 거리 기록 = 방문 표시
```

```cpp
// DFS 뼈대 — 종료조건 먼저
void dfs(int u) {
    visited[u] = true;
    for (int v : adj[u]) if (!visited[v]) dfs(v);
}
```

## 핵심 4 — 선택 기준

| 질문에 이게 보이면 | 고른다 |
|---|---|
| "최단 거리", 가중치 없음 | BFS |
| "모든 경우", "가능한 조합", "경로가 있는가" | DFS / 백트래킹 |
| 가중치 있는 최단경로 | 다익스트라 (음수면 벨만-포드) |
| "우선순위", "가장 큰/작은 것 반복 추출" | 힙 |
| "정렬 유지 + 삽입/삭제" | BST(map/set) |
| "선행 관계·의존 순서" | 위상 정렬 (DAG) |
| "연결됐는가·같은 그룹인가" | Union-Find |
