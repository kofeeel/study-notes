# OS 핵심 - 공룡책 (시간 부족 시 핵심만)

> 교재: **Operating System Concepts** (Silberschatz, 일명 공룡책)
> 참고 정리: https://github.com/yonghwankim-dev/OperatingSystem_Study (챕터별 요약 블로그)
> 전략: 전체 X. 게임 클라 면접/필기 **빈출 챕터만** 압축.

## 🔥 필독 챕터 (게임 클라 빈출)

### Ch3. Processes
- **프로세스 vs 스레드** (메모리 구조 차이 — 면접 단골)
- PCB, 프로세스 상태 전이 (New→Ready→Running→Waiting→Terminated)
- IPC (공유메모리 vs 메시지 패싱)

### Ch4. Thread & Concurrency
- 멀티스레드 모델 (1:1, M:1, M:N)
- 스레드 풀
- race condition 진입점

### Ch5. CPU Scheduling ⭐
- FCFS / SJF / Priority / RR
- MLQ / MLFQ (현대 OS 표준)
- 선점 vs 비선점
- Turnaround / Waiting time 계산 (필기 계산문제 가능)

### Ch6. Synchronization ⭐⭐ (최빈출)
- Critical Section 문제 (3조건: 상호배제/진행/한정대기)
- **Mutex vs Semaphore** (Binary / Counting)
- Monitor
- Peterson's Solution (개념만)
- 동기화 하드웨어 (CAS, Test-And-Set)

### Ch8. Deadlocks ⭐
- **4조건** (상호배제 / 점유대기 / 비선점 / 순환대기)
- Prevention vs Avoidance vs Detection 차이
- Banker's Algorithm (개념 수준)

### Ch9. Main Memory
- Paging, Segmentation
- **단편화** (내부 vs 외부)
- 주소 변환 (논리주소 → 물리주소, MMU)

### Ch10. Virtual Memory ⭐
- Demand Paging
- **Page Fault 처리 흐름** (단계별 설명 가능해야)
- 페이지 교체 (LRU / FIFO / Optimal / Clock)
- TLB, Thrashing
