# 게임 물리 출제 예상 (최소 집중)

## 1. 충돌 판정 (가장 중요)

### AABB (Axis-Aligned Bounding Box)
- 축에 정렬된 박스, 회전 X
- 가장 빠른 광역 검사
```cpp
bool AABBOverlap(AABB a, AABB b) {
    return (a.max.x >= b.min.x && a.min.x <= b.max.x) &&
           (a.max.y >= b.min.y && a.min.y <= b.max.y) &&
           (a.max.z >= b.min.z && a.min.z <= b.max.z);
}
```

### Sphere
- 두 구 중심 거리² < (반지름 합)²
- 가장 빠름, 회전 무관
```cpp
bool SphereOverlap(Sphere a, Sphere b) {
    float distSq = (a.center - b.center).SizeSquared();
    float r = a.radius + b.radius;
    return distSq < r * r;  // sqrt 회피
}
```

### OBB (Oriented Bounding Box)
- 회전 가능한 박스, AABB보다 정확
- **SAT**로 판정

### SAT (Separating Axis Theorem)
- 두 볼록 다각형 사이 **분리 축이 하나라도 존재 → 충돌 X**
- 모든 후보 축에서 투영 겹침 → 충돌
- **후보 축** (2D 다각형): 각 변의 법선
- **후보 축** (3D OBB): 각 OBB의 3축 + 두 OBB 축의 외적 (15개)

### Capsule
- 두 점 + 반지름
- 캐릭터 콜리전 표준 (모서리에 안 걸림)
- 판정: 점-선분 거리 < 반지름

### 광역 검사 (Broad Phase)
- 모든 쌍 검사하면 O(n²) → 공간 분할로 줄이기
- **Quad/Octree, BVH, KD-Tree, Spatial Hash**

## 2. 강체역학 기초

### 선형 운동
- 위치 → 속도 → 가속도
- 뉴턴 2법칙: **F = ma**
- 운동량 **p = mv** (보존됨, 외력 없을 시)

### 회전 운동
- 각도 → 각속도(ω) → 각가속도(α)
- 토크 **τ = Iα** (I: 관성 모멘트)
- 각운동량 **L = Iω**

### 관성 모멘트 (I)
- 회전 저항 (질량의 회전판)
- 구: I = (2/5) m r²
- 박스: I = (1/12) m (a² + b²)

### 운동량 보존
- 외력 없으면 운동량 일정
- 충돌 시 운동량 보존 → 충돌 후 속도 계산 가능

## 3. 적분 방법 (Time Integration)

### Euler 적분 (가장 단순, 불안정)
```cpp
v += a * dt;
p += v * dt;  // 옛 v 사용
```
- 에너지 증가하며 발산하는 경향

### Semi-implicit Euler (게임 표준)
```cpp
v += a * dt;
p += v * dt;  // 새 v 사용 (한 줄만 바뀜)
```
- 매우 안정, 모든 게임에서 표준

### Verlet 적분
- 위치 기반, 속도 명시 안 함
- 클로스/입자 시뮬레이션에 적합

### RK4 (Runge-Kutta 4)
- 정확도 高, 계산량 多
- 일반 게임엔 오버킬 (시뮬레이션용)

## 4. 충돌 응답

### 탄성 충돌 (1D)
- 운동량 + 운동 에너지 둘 다 보존
```
v1' = ((m1-m2)v1 + 2*m2*v2) / (m1+m2)
v2' = ((m2-m1)v2 + 2*m1*v1) / (m1+m2)
```

### 비탄성 충돌
- 운동량만 보존 (에너지 일부 손실)
- 완전비탄성 = 충돌 후 같은 속도

### 반발계수 e
- e = 0: 완전 비탄성 (붙음)
- e = 1: 완전 탄성 (에너지 100% 보존)
- 0 < e < 1: 일반 충돌

### 마찰
- 정지 마찰: F ≤ μs × N
- 운동 마찰: F = μk × N (μk < μs 보통)

## 5. 기타 자주 묻는 것

### Tick 독립 물리
- 프레임 레이트 변화에도 동일 시뮬레이션 결과
- **Fixed Timestep** + 보간 사용 (Unreal/Unity 표준)

### 공간 분할 (Broadphase)
- Sweep and Prune (SAP)
- BVH (Bounding Volume Hierarchy)
- Spatial Hash
