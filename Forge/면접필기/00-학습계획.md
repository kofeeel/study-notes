# 게임 클라 프로그래머 필기 준비 - 학습 계획

## 목적
게임 클라이언트 프로그래머 인턴 채용 대비 (2단계).
- **1차 온라인 시험**: 알고리즘 위주, 난이도 낮음 → 구현력 회복이 핵심
- **2차 다대다 면접**: 포트폴리오·자소서 기반 기술 질문 → 진짜 승부처

> ⚠️ 최신 채용 정보 반영: CS/그래픽스/물리 객관식 필기는 비중 낮음(또는 없음). 깊게 파지 말 것.

## 우선순위
1. **알고리즘** (Lv1~Lv2, 난이도 낮음) — 1차 시험. 매일 손풀기로 구현력 회복
2. **포트폴리오 + 면접 대비** — 2차 승부처. 포폴 설명 + 예상 질문 + 자신감
3. **C++** — 시험 구현 + 면접 개념 (Effective C++ 핵심)
4. **언리얼 개념** — 면접 기술 질문 (내 프로젝트와 직결)
5. **CS / 그래픽스 / 물리** — 면접 답변용 핵심 개념만 (필기 벼락치기 ❌)

## 실행 로드맵 (순차 태스크)

### Phase 1: 1차 시험 — 알고리즘 (난이도 낮음) — 최우선
- [ ] **T1.** 게임클라 우선 3문제 ([[프로그래머스-문제집]]: 게임맵최단거리·행렬곱셈·타겟넘버)
- [ ] **T2.** 알고리즘 누적 (Lv1 20 + Lv2 10) — 매일 손풀기, 구현력 회복
- [ ] **T3.** 손코딩 연습 (IDE 자동완성 없이) + 못 푼 문제 재풀이

### Phase 2: 2차 면접 — 포폴 + 기술 (진짜 승부)
- [ ] **T4.** 포트폴리오 설명 정리 + 예상 질문 답변 (왜 이렇게 구현했나 = 트레이드오프)
- [ ] **T5.** C++ 1회독 ([[02-CPP-알고리즘]] + Effective C++ Item 13~17, 32~37)
- [ ] **T6.** 언리얼 개념 정리 (리플렉션/Replication/GC + 내 프로젝트 연결)
- [ ] **T7.** CS/그래픽스 면접 핵심만 ([[01-CS]] [[03-그래픽스]]: 메모리·포인터·스레드·렌더 파이프라인·조명모델)

### Phase 3: 디자인 패턴 보강 (면접용) — 여유 시
- [ ] **T8.** 07-디자인패턴.md 생성 (싱글톤/옵저버/스테이트/스트래터지/팩토리)
- [ ] **T9.** 디자인 패턴 + OOP SOLID 학습
- [ ] **T10.** 패턴별 게임 예시 답변 준비 (스테이트=FSM → 적/보스 AI 연결)

> 매일 알고리즘(Phase 1)은 고정. 면접 일정 잡히면 Phase 2 집중. 디자인패턴은 여유 시.
