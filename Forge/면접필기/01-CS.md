# CS 출제 예상 토픽 (최우선)

## 1. 메모리 계층 + 캐시

```
레지스터 < L1 < L2 < L3 < 메인메모리 < 디스크
(빠름)                                    (느림)
```

- **캐시 히트율**: 자주 쓰는 데이터가 캐시에 있을 확률
- **참조 지역성**
  - 시간 지역성: 최근 접근한 데이터 재접근
  - 공간 지역성: 인접 메모리 접근 (배열이 연결리스트보다 빠른 이유)
- **캐시 미스 종류**: Compulsory / Conflict / Capacity
- **Write 정책**: Write-through (즉시 메인에 기록) vs Write-back (지연 기록)
- **의도**: CPU-메모리 속도 차이로 인한 데이터 병목 해소

## 2. 가상메모리 + 페이징

- 가상주소 → 물리주소 변환 (**MMU**, **TLB** 활용)
- 페이지 테이블, 페이지 폴트 (Disk → Memory 로드)
- **페이지 교체 알고리즘**: LRU / FIFO / Clock / LFU
- **단편화**
  - 외부단편화: 가변 분할에서 발생 (페이징은 해결)
  - 내부단편화: 고정 분할에서 발생 (페이징에서 잔존)
- **Demand Paging**: 필요할 때만 메모리 로드
- **Copy-on-Write**: 공유 페이지를 수정 시점에만 복사

## 3. OS 스케줄링

- **선점 vs 비선점**
- 알고리즘
  - **FCFS**: 먼저 온 순
  - **SJF**: 짧은 작업 우선 (기아 발생 가능)
  - **Round Robin**: 타임 슬라이스 순환
  - **MLFQ**: 다단계 큐, 현대 OS 표준
- **Context Switch 비용**: 레지스터 저장/복원, 캐시 무효화
- **스레드 vs 프로세스**
  - 프로세스: 독립 메모리 공간
  - 스레드: 메모리 공유, Context Switch 가벼움

## 4. 동기화

- **Race Condition**: 여러 스레드가 공유 자원에 동시 접근
- **Critical Section**: 동시 접근 막을 코드 구간
- **동기화 도구**
  - **Mutex**: 상호 배제 (소유자 있음)
  - **Semaphore**: 카운터 기반 (Counting / Binary)
  - **Monitor**: 자동 락 (C# lock, Java synchronized)
  - **Spinlock**: 락 대기 시 busy-wait (짧은 구간 유리)
- **Deadlock 4조건**: 상호배제 / 점유대기 / 비선점 / 순환대기
  - 예방: 4조건 중 하나 깨기
  - 회피: Banker's algorithm
- **Atomic operation**: CAS (Compare-And-Swap)

## 5. TCP/UDP + 네트워크

- **TCP**
  - 연결지향, 신뢰성, 흐름제어, 혼잡제어
  - **3-way handshake**: SYN → SYN-ACK → ACK
  - **4-way termination**: FIN → ACK → FIN → ACK
- **UDP**
  - 비연결, 빠름, 데이터그램
  - 게임/실시간 표준 (손실 허용)
- **OSI 7계층** vs **TCP/IP 4계층**
  ```
  OSI:    Application | Presentation | Session | Transport | Network | DataLink | Physical
  TCP/IP: Application                          | Transport | Internet | NetworkAccess
  ```
- **게임 네트워크**: UDP + 자체 reliability 레이어 (UE Replication은 UDP)

## 6. DBMS

- **정규화**
  - 1NF: 원자 값
  - 2NF: 부분 함수 종속 제거
  - 3NF: 이행 함수 종속 제거
  - BCNF: 결정자가 후보 키
- **트랜잭션 ACID**
  - Atomicity (원자성)
  - Consistency (일관성)
  - Isolation (격리성)
  - Durability (영속성)
- **인덱스**: B-Tree (범위 검색 강) vs Hash (점 검색 강)
- **JOIN**: Inner / Left / Right / Full Outer / Cross
