# 17. 프로그래머 레퍼런스 — AI 시스템 구현 가이드

> 스텔라블레이드 149개 BT 실데이터 기반. 디자이너가 사용할 빌딩 블록을 만드는 프로그래머 관점.

## 1. 구현 우선순위 (80/20 법칙)

전체 16,319 노드 중 상위 7개 커스텀 노드가 80% 커버:

| 우선순위 | 노드 | 사용 횟수 | UE5 구현 방향 | 난이도 |
|---------|------|----------|-------------|--------|
| ★★★ | UseSkill | 2,182 | BTTask: ASC→TryActivateAbility, SkillName 배열→Tags 매칭 | 중 |
| ★★★ | CheckActorEffect | 1,873 | BTDecorator: ASC→HasMatchingGameplayTag | 하 |
| ★★★ | DistanceToTarget | 956 | BTDecorator: FVector::Dist, CompareOP enum | 하 |
| ★★ | Blackboard (Task+Dec) | 1,541 | UE5 기본 제공 (BTTask_SetBBValue + BTDecorator_Blackboard) 확장 | 하 |
| ★★ | AggroLevel | 555 | BTDecorator: GameplayTag 체크 (State.Aggro.Peaceful/Battle) | 하 |
| ★★ | CheckActorStat | 278 | BTDecorator: ASC→GetNumericAttribute, CompareOP | 하 |
| ★ | Random | 389 | BTDecorator: FMath::RandRange(0,Range) CompareOP CheckValue | 하 |

→ 이 7개만 만들면 149개 BT의 80%를 재현 가능

### 2.1 태스크 노드 (14종)

#### 1. SBBTTask_SbUseSkill (2,182회)

- **파라미터**: `SkillName: FName[]`, `SkillComboType: ESBAISkillComboType`, `bUseSkillCommand: bool`, `bSubTarget: bool`
- **UE5 구현**: `UBTTask_ActivateAbility` → `ASC->TryActivateAbilitiesByTag(SkillTags)`
- **핵심**: SkillName이 **배열** → 런타임 랜덤/우선순위 선택. GAS에서는 AbilityTag 배열로 매핑.

```cpp
// BTTask_ActivateAbility.cpp 핵심 로직
EBTNodeResult::Type UBTTask_ActivateAbility::ExecuteTask(UBehaviorTreeComponent& OwnerComp, uint8* NodeMemory)
{
    AAIController* AIC = OwnerComp.GetAIOwner();
    UAbilitySystemComponent* ASC = UAbilitySystemBlueprintLibrary::GetAbilitySystemComponent(AIC->GetPawn());
    if (!ASC) return EBTNodeResult::Failed;

    // SkillName 배열 → 랜덤 또는 우선순위 선택
    for (const FGameplayTag& Tag : SkillTags)
    {
        if (ASC->TryActivateAbilitiesByTag(FGameplayTagContainer(Tag)))
            return EBTNodeResult::InProgress; // Ability가 종료 시 FinishLatentTask 호출
    }
    return EBTNodeResult::Failed;
}
```

#### 2. SBBTDecorator_SbDistanceToTarget (956회)

- **파라미터**: `Distance: float`, `CompareOP: ESBCompare`
- **UE5 구현**: `FVector::Dist(OwnerLoc, TargetLoc)` + ESBCompare 열거형으로 비교

```cpp
bool UBTDecorator_CompareDistance::CalculateRawConditionValue(
    UBehaviorTreeComponent& OwnerComp, uint8* NodeMemory) const
{
    AActor* Owner = OwnerComp.GetAIOwner()->GetPawn();
    AActor* Target = Cast<AActor>(OwnerComp.GetBlackboardComponent()->GetValueAsObject(TargetKey));
    if (!Owner || !Target) return false;

    float Dist = FVector::Dist(Owner->GetActorLocation(), Target->GetActorLocation());
    return EvaluateCompareOP(Dist, Distance, CompareOP);
}
```

## 3. 핵심 시스템 아키텍처

### 3.1 이펙트(상태) 시스템 → GAS GameplayTag

SB에서 가장 많이 사용된 시스템 (1,873회). 이펙트 = 런타임 상태 플래그.

```
SB 방식:                                  UE5 GAS 방식:
UseEffect("M_Raven_BuffFX")          →   ApplyGE → GrantTag("AI.State.Raven.BuffFX")
CheckActorEffect("BuffFX", Self)     →   HasMatchingGameplayTag("AI.State.Raven.BuffFX")
CheckActorEffect("BuffFX", Target)   →   Target.ASC->HasMatchingGameplayTag(...)
```

**태그 계층 설계 (권장):**

```
AI.State
├── AI.State.Phase.Default
├── AI.State.Phase.Phase2
├── AI.State.Phase.Phase3
├── AI.State.Combat.ParryChain
├── AI.State.Combat.GrabChain
├── AI.State.Combat.ComboCheck
├── AI.State.Cooldown.ChaseGrab
├── AI.State.Cooldown.MoveCombo
├── AI.State.Aggro.Peaceful
├── AI.State.Aggro.Battle
├── AI.State.Aggro.Trace
└── AI.State.Dead
```

**EffectAlias → Tag 매핑은 DataTable로 관리** (하드코딩 금지):

```cpp
// DT_AIEffectAliasMap: FName EffectAlias → FGameplayTag Tag
FGameplayTag UAIEffectAliasHelper::ResolveTag(const FName& Alias)
{
    const FAIEffectAliasRow* Row = AliasTable->FindRow<FAIEffectAliasRow>(Alias, TEXT(""));
    return Row ? Row->GameplayTag : FGameplayTag::EmptyTag;
}
```

### 3.4 CompareOP 열거형 (공통 유틸리티)

`DistanceToTarget`, `CheckActorStat`, `Random`, `CheckSummonedCount` 4개 노드에서 공유.

```cpp
UENUM(BlueprintType)
enum class ESBCompare : uint8
{
    Less            UMETA(DisplayName = "<"),
    LessOrEqual     UMETA(DisplayName = "<="),
    Equal           UMETA(DisplayName = "=="),
    NotEqual        UMETA(DisplayName = "!="),
    Greater         UMETA(DisplayName = ">"),
    GreaterOrEqual  UMETA(DisplayName = ">=")
};

// 공통 유틸 함수 (BT 노드 공유)
static bool EvaluateCompareOP(float A, float B, ESBCompare OP)
{
    switch (OP)
    {
    case ESBCompare::Less:            return A < B;
    case ESBCompare::LessOrEqual:     return A <= B;
    case ESBCompare::Equal:           return FMath::IsNearlyEqual(A, B);
    case ESBCompare::NotEqual:        return !FMath::IsNearlyEqual(A, B);
    case ESBCompare::Greater:         return A > B;
    case ESBCompare::GreaterOrEqual:  return A >= B;
    }
    return false;
}
```

### 3.5 ActorType 열거형 (Self/Target 선택)

`CheckActorEffect`, `IsAlive`, `CheckActorStat` 등 다수 데코레이터에서 공유.

```cpp
UENUM(BlueprintType)
enum class ESBAIActorType : uint8
{
    Self    UMETA(DisplayName = "Self"),
    Target  UMETA(DisplayName = "Target")
};

// 헬퍼: ActorType → ASC 반환
UAbilitySystemComponent* UBTNodeHelper_AI::GetASCByActorType(
    UBehaviorTreeComponent& OwnerComp, ESBAIActorType ActorType)
{
    if (ActorType == ESBAIActorType::Self)
    {
        return UAbilitySystemBlueprintLibrary::GetAbilitySystemComponent(
            OwnerComp.GetAIOwner()->GetPawn());
    }
    // Target: Blackboard에서 가져옴
    AActor* Target = Cast<AActor>(
        OwnerComp.GetBlackboardComponent()->GetValueAsObject(TargetBBKey));
    return Target ? UAbilitySystemBlueprintLibrary::GetAbilitySystemComponent(Target) : nullptr;
}
```

### FlowAbort 설정 가이드

| 데코레이터 | 권장 FlowAbort | 이유 |
|-----------|---------------|------|
| CheckGameplayTag (IsAlive) | Both | 타겟/자신 사망 즉시 중단 필수 |
