# 18. 디자이너 레퍼런스 — BT 패턴 & 밸런스 수치

> 스텔라블레이드 149개 BT 실데이터 기반. 프로그래머가 만든 노드를 조립하는 디자이너 관점.

## 1. BT 기본 스켈레톤 (복사해서 시작)

모든 149개 BT가 공유하는 루트 구조. 새 몬스터 만들 때 이 구조에서 시작:

```
Root Selector
 └── Selector [IsAlive(Self), abort=Both]
     ├── DetectTarget [DetectResult(==)]
     ├── Selector [IsAlive(Target)]
     │   └── Wait(1.0s)                          ← 타겟 사망 시 잠시 대기
     └── Selector [IsAlive(Target)]
         ├── Wait(2.0s) [CheckEffect(Target.부활아이템)]  ← 부활 중 공격 금지 (공정성)
         ├── Selector [CheckEffect(Target.다운)]
         │   └── CautionToTarget [TimeLimit(3.0s)]  ← 다운된 적 경계
         └── Selector [AggroLevel(Peaceful)]
             └── ★ 여기에 몬스터별 전투 로직 ★
```

설명:
- `IsAlive(Self) abort=Both`: 죽으면 BT 전체 즉시 중단
- `DetectTarget`: 매 틱 타겟 갱신
- 부활 아이템 2초 대기: 플레이어 경험 보호 (부활 직후 피격 방지)
- `AggroLevel` 필터: 비전투 시 공격 로직 진입 차단

## 2. 보스 BT 패턴 템플릿

### 2.1 페이즈 분기 구조

실제 사용된 보스별 HP 임계값:

| 보스 | Phase 1 | Phase 2 | Phase 3 |
|------|---------|---------|---------|
| Raven | HP > 60% | HP ≤ 60% | - |
| ExoSuit | HP > 70% | HP ≤ 70% | HP ≤ 30% |
| ElderPhase2 | HP > 60% | HP ≤ 60% | HP ≤ 40% |
| Behemoth | HP > 50% | HP ≤ 50% | - |

패턴:

```
★ 전투 로직 위치 ★
├── Selector [CheckStat(HP>X%) && CheckStance(Default)]
│   └── ★ Phase 1 행동들 ★
├── Selector [CheckStat(HP≤X%) && CheckStance(Phase2)]
│   └── ★ Phase 2 행동들 ★
└── Selector [CheckStat(HP≤Y%) && CheckStance(Phase3)]
    └── ★ Phase 3 행동들 ★
```

### 2.2 페이즈 전환 연출

페이즈 진입 시 반드시 포함:

```
Sequence [Blackboard(PhaseInit)]      ← 한 번만 실행
├── UseableTimeReset × 6~8            ← 모든 쿨다운 초기화
├── UseEffect(페이즈전환이펙트)        ← 스탠스 변경 + 연출
└── Blackboard(PhaseInit) = done       ← 플래그 세팅
```

### 2.3 보스 내부 행동 우선순위 (Selector 순서)

Raven Phase 1 기준 실제 순서:

```
Phase 1 Selector (HP>60%, Default 스탠스)
├── 1. [AimMe] 회피              ← 최우선: 플레이어 조준 시 즉시 회피
├── 2. [HitProjectile] 회피      ← 원거리 피격 반응
├── 3. [베타소드오라] 베타회피    ← 특정 스킬 반응
├── 4. [러시대기] 경계            ← 특수 상태 처리
├── 5. 패리 프리뷰 → 패리 → 카운터  ← 핵심 콤보 체인
├── 6. [거리≥400] 추격 공격      ← 거리 기반 행동
├── 7. [쿨다운OK] 콤보 공격      ← 일반 공격
├── 8. 기본 베기                  ← fallback 공격
└── 9. 경계 + 이동               ← 최종 fallback
```

**핵심 원칙**: 위 순서는 Selector이므로 **위에서부터 조건이 맞으면 실행**. 반응형이 위, 일반 공격이 아래.

## 3. 일반 몬스터 패턴

### 3.1 역할별 템플릿

**근접 Attacker** (BotAttacker 참고, 329노드):

```
├── [스폰이벤트] → PlayShow + 개막 공격 (Missile 40%|Stamp 30%|Dash 30%)
├── [MetaAI 명령] → MetaAI 태스크
├── [거리≥800] → 돌진 공격
├── [거리<800 && 쿨다운OK] → 근접 콤보
├── [피격 반응] → 회피 or 카운터
└── 경계 + 이동
```

**원거리 Range** (BotRange 참고):

```
├── [거리<300] → 후퇴 (MoveBack)
├── [거리300~800] → 사격 (Shot, LaserCrossFire)
├── [거리≥800] → 경계 유지
└── [피격] → 회피
```

**잡몹** (MiteA 참고, ~50노드):

```
├── DetectTarget
├── [IsAlive(Target)] → MoveToTarget → UseSkill(기본공격)
└── Wait
```

### 3.2 MetaAI 연동 패턴 (그룹 전투)

```
Sequence [AggroLevel(Battle) && CheckEffect(LV_MetaAction)]
 └── MetaAI    ← 메타AI가 "공격해라" / "대기해라" 명령

Sequence [AggroLevel(Battle) && IsActiveSkill(NOT)]
 ├── UseSkill(BattleEnd)    ← 전투 종료 연출
 └── MoveToHome             ← 귀환
```

## 4. 밸런스 수치 레퍼런스

### 4.1 거리 임계값 (DistanceToTarget)

전체 956회 사용에서 추출한 실제 거리값:

| 거리 | 용도 | 예시 |
|------|------|------|
| 250 | 밀착 (근접 전용) | Raven 경계 최소 거리 |
| 300 | 근접 전환점 | 베타소드오라 회피 트리거 |
| 400 | 근접/중거리 경계 | ExoSuit 회피 판정, 추격 공격 |
| 800 | 중거리/원거리 경계 | ExoSuit 원거리 스킬 |
| 1400 | 경계 범위 상한 | Raven 경계 이동 상한 |
| 2800 | 원거리 특수 | Elder Explosion/Shot 트리거 |

### 4.2 HP 임계값 (CheckActorStat)

| HP% | 용도 | 사용 보스 |
|-----|------|---------|
| 70% | 1→2 페이즈 | ExoSuit |
| 60% | 1→2 페이즈 (표준) | Raven, Elder, 다수 |
| 50% | 2페이즈 전환 | Behemoth 등 |
| 40% | 2→3 페이즈 | Elder |
| 30% | 최종 페이즈 | ExoSuit |

### 4.3 확률 분포 (Random)

| 확률 | 용도 | 예시 |
|------|------|------|
| 30% | 낮은 확률 행동 | 사격 피격 후 회피 |
| 40% | 중간 낮음 | BotAttacker 스폰 Missile |
| 50% | 표준 (동전 던지기) | Raven 조준 시 회피 |
| 70% | 높은 확률 | Elder AimMe 회피 |

**관찰**: 확률 합이 Selector에서 100% 초과 가능 — 순서가 우선이므로 앞 노드가 먼저 체크됨

### 4.4 타이머 (TimeLimit)

| 시간 | 용도 | TimerName 패턴 |
|------|------|---------------|
| 1.8s | 짧은 경계 (보스) | CautionTimer, RushWaitTimer |
| 3.0s | 다운 경계 | DownCautionTimer |
| 3.6s | 이상상태 대기 | AbnormalTimer |
| 8.0s | 긴 이동 | StartTimer |

### 4.5 대기 시간

| 시간 | 용도 |
|------|------|
| 0.5~1.0s | 타겟 사망 후 짧은 대기 |
| 2.0s | 부활 아이템 대기 |
| WaitRandom(Min~Max) | 행동 사이 자연스러운 딜레이 |

## 5. 콤보 체인 설계 가이드

### 5.1 이펙트 플래그 체인

Raven 패리 체인을 레퍼런스로:

```
[상태 없음] → ParryPreview1 → (ParryPreviewChain1 이펙트 ON)
                    ↓
[Chain1 ON] → Parry → (ParryChain 이펙트 ON)
                    ↓
[ParryChain ON, GrabCheck OFF] → BetaGrabChain → BetaCounterGrab
[ParryChain ON, GrabCheck ON]  → BetaRapidCombo | BetaChargeCombo
                    ↓
[대안 경로] → ParryPreview2 → (ParryPreviewChain2 ON)
                    ↓
[Chain2 ON, Chain1 OFF] → ParryCounterCombo
```

**핵심 규칙**:
1. 각 스킬이 성공하면 **다음 단계 이펙트를 ON** (`UseEffect`)
2. 다음 Selector는 **이전 이펙트 ON** + **다다음 이펙트 OFF** 조합으로 현재 단계 확인
3. 분기는 NOT 조건으로 대안 행동 제공 (잡기 vs 콤보)

### 5.2 스킬 배열 활용

하나의 `UseSkill` 노드에 여러 스킬 이름:

```
UseSkill(["EvadeLeft", "EvadeRight"])  → 좌/우 랜덤 회피
UseSkill(["RapidCombo", "ChargeCombo", "Grab"])  → 세 가지 중 랜덤
```

**용도**: 같은 조건에서 다양한 행동 → 플레이어가 패턴을 읽기 어렵게

## 6. 네이밍 컨벤션

### BT 파일명

- Monster: `M_{몬스터명}_AI` (예: `M_Raven_AI`)
- NPC: `N_{NPC명}_AI` (예: `N_Adam_AI`)
- 변형: `_{지역}` (Beach, Wasteland), `_Nikke_` (DLC), `_TR` (트레이닝)

### 스킬명

- `M_{몬스터}_` 접두사 + 행동명
- 예: `M_Raven_BetaEvadeLeft`, `M_ExoSuit_PhaseChange`
- 공통: `M_Common_HitProjectileResult`

### 이펙트명

- 스킬 체인: `M_{몬스터}_{상태명}` (예: `M_Raven_ParryChain`)
- 시스템: `Item_Resurrection_Ground`, `LV_MetaAction`

### 타이머명

- `{행동}Timer{번호}` (예: `CautionTimer1`, `RushWaitTimer1`)
