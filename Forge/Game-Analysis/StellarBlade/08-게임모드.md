# 08. 게임 모드

## 게임 모드 개요
- **싱글플레이어 전용** — 멀티플레이어 코드 없음
- GameLiftServerSDK 플러그인 존재 → 백엔드/매칭 서비스 연동 가능성 (리더보드?)
- Lua 스크립팅 (slua_unreal) — 게임 로직 일부를 Lua로 관리

## 시스템 에셋 (GameDesign/System — 100 파일)

### 다이얼로그 시스템
- `Dialogue/` 하위 카메라/애니메이션 템플릿:
  - `ActorBounds/` — 캐릭터 바운드 본 (1인~4인 대화)
  - `TemplateAnimation/` — 대화 카메라 애니메이션 (CloseUp, OverShoulder, SideView, WaistBack)
  - `TemplateShot/` — 카메라 샷 프리셋
  - NPC별 전용 템플릿 (Digger, Kaya, Orcal, Lily)
- 데이터 드리븐 대화 시스템: 카메라 앵글과 애니메이션을 템플릿으로 관리

### 낚시 시스템
- `Fishing/BP_Bobber.uasset` — 낚시 찌
- 미니게임으로 존재

### AI 포메이션
- `AIFormation.uasset` — 그룹 AI 대형 관리

### 기타
- `AngelsCorpseSeq` — 엔젤 시체 시퀀스 (스토리 연출)
- `SBZoneTriggerActorItem_Blueprint` — 존 트리거

## 진행 시스템
- **선형 + 반오픈**: 챕터별 진행이지만 오픈 필드 탐색 가능
- **보스 챌린지**: `BP_Bosschallenge_*` — 보스 재도전 시스템
- **캠프**: `BP_CampArea` — 세이브/회복 포인트

## 설계 패턴
1. **Theater 시스템**: 3,272개 시어터 에셋 → 대규모 시네마틱 연출 시스템
2. **데이터 드리븐 다이얼로그**: 카메라 앵글/샷을 템플릿 에셋으로 관리
3. **AreaControlVolume**: 전투 영역을 볼륨으로 정의 → 입장 시 전투 시작/잠금
4. **ZoneEnv 시스템**: 영역별 환경 변화 관리
5. **Lua 스크립팅**: slua_unreal → 이벤트/퀘스트 로직을 Lua로 유연하게 관리
