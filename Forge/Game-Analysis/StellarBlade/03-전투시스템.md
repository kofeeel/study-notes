### 쇼메이커(Showmaker) — 자체 연출 툴
Seq_ 64,877개의 정체. 레벨 시퀀스를 **제외한** 대부분의 연출을 담당하는 자체 툴.
- 애니메이션 시퀀스 등록, 스킬 구간 설정, 타격 결과 처리, FX/사운드 연동
- **비의존성**: 애니메이션/블루프린트에 의존하지 않고 연출 재생 가능
- **실시간 프리뷰**: 게임 내 연출과 동일한 화면을 툴에서 확인
- **리소스 통합 관리**: 연출에 필요한 모든 리소스를 한곳에서 관리
- 데이터 테이블 임포트/익스포트 지원

### 타격 판정 시스템 — 이중 방식

| 방식 | 특징 | 적용 대상 |
|------|------|----------|
| **트라이앵글** | 이전/현재 프레임 소켓 위치로 삼각형 구축 | 검 (얇은 무기, 정밀 검출) |
| **히트박스 스윕 트레이스** | 셰이프 컴포넌트 + 이전 트랜스폼 기록 | 몸통 박치기, 느리고 큰 무기, 영역 판정 |

**트랜스폼 보간 처리**: 프레임 레이트 저하/빠른 공격 시 궤적 누락 방지
- 로우 애니메이션 데이터 기반 보간 위치에 파티클 추가 생성 → 부드러운 궤적
- **경사지 보정**: Look-at IK로 캐릭터 상체가 몬스터 중점을 바라보게 함 → 타격 궤적 어긋남 방지

### 타격감 극대화 기법 (3층 구조)

| 기법 | 상세 | 구현 방식 |
|------|------|----------|
| **히트 스탑** | 타격 시 애니메이션 일시 정지 | IK로 검 밀착감 보정 (지나치거나 닿지 않는 문제 해결) |
| **본 쉐이크** | 피격 시 주요 본 위치/회전 비틀기 | 피격 애니메이션과 별개로 적용 → 충격 시각화 |
| **버텍스 쉐이크** | 피격 부위 버텍스를 물리적으로 눌러줌 | 머티리얼 WPO(World Position Offset) 활용 |

### 실시간 절단 시스템 (Dismemberment)
모델링 교체 방식 대신 **프로시저럴 매시** 활용:
1. 절단 대상 본의 스킨 웨이트 버텍스만으로 ProceduralMesh 생성
2. 나머지는 SkeletalMesh 유지 + 버텍스 컬러 마스킹으로 숨김
3. 절단 매시에 임펄스 → 비산 연출
4. 레그돌 트랜스폼 기반 버텍스 스키닝 → 절단면 자연스러운 연결

**최적화**: 트라이앵글 인덱스 사전 캐싱 + 버텍스 스키닝 별도 스레드 수행

### PS5 60FPS CPU 최적화

| 기법 | 상세 | 효과 |
|------|------|------|
| **프레임 분산 처리** | 파티클/발사체 생성을 1ms/프레임으로 제한, 지연 보정 | 스파이크 방지 |
| **PhysX 최적화** | 불필요 본 RigidDynamic 제외 + 캡슐 대체 | 물리 부하 제거 |
| **루트 모션 병렬화** | 3ds Max에서 루트모션 사전 추출 → 별도 데이터 관리 | 멀티스레드 애니메이션 |
| **캐릭터 무브먼트 병렬화** | 매니저 클래스로 Move 로직 병렬 수행, 오버랩/피직스는 지연 처리 | **2.8ms → 1ms (64% 감소)** |

## 설계 패턴 분석

### 에셋 분석 기반
1. **데이터 드리븐 전투**: MoveCurve로 공격 궤적을 외부 데이터로 관리 → 디자이너가 코드 수정 없이 전투 감각 조절 가능
2. **GAS 대신 커스텀**: 액션 게임의 프레임 단위 전투 제어에는 GAS보다 커스텀 시스템이 유리
3. **페이즈 기반 보스**: AI 에셋을 페이즈별로 분리 (ElderPhase1, ElderPhase2) → 페이즈 전환 시 BT 교체
4. **Lua 스크립팅**: slua_unreal 플러그인으로 전투 로직 일부를 Lua로 작성 추정

### 언리얼 페스트 발표 기반 (시프트업 공식)
5. **쇼메이커 = 핵심 파이프라인**: 에셋 비의존적 연출 → 파트 간 병렬 작업 가능
6. **이중 타격 판정**: 무기 형태에 따라 Triangle / Sweep 전환 → 정밀도와 성능 균형
7. **3층 타격감**: HitStop + BoneShake + VertexShake → 레이어드 임팩트
8. **프로시저럴 절단**: 런타임 메시 생성 → 사전 모델링 불필요, 다양한 절단각 대응
9. **공격적 병렬화**: CharacterMovement를 매니저 기반 병렬 처리 (64% CPU 절감)
10. **프레임 분산**: 파티클/발사체 생성을 시간 제한 → 보스전 스파이크 방지
