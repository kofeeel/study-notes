> 출처: [[raw/[언리얼 페스트 2024] 스텔라 블레이드_ 화려함과 성능의 조화 – 전투 시스템 및 최적화 전략]]

### AI 탐색 시스템
- 시야 및 소리 영역 내 플레이어 존재 여부 검사
- **발견 수치** 기반 → 일정 수준 초과 시 추적 상태 전환

### AI 포지셔닝 시스템 (핵심)
플레이어 중심 **55×55 셀(Cell)** 기반 그리드 시스템:

```
┌──────────────────────────────────┐
│         55 × 55 Cell Grid        │
│                                  │
│    ┌─┬─┬─┬─┬─┐                  │
│    │ │ │ │ │ │  ← 각 셀에 객체   │
│    ├─┼─┼─┼─┼─┤     정보 저장     │
│    │ │ │P│ │ │  P = Player       │
│    ├─┼─┼─┼─┼─┤                  │
│    │ │ │ │ │ │                  │
│    └─┴─┴─┴─┴─┘                  │
└──────────────────────────────────┘
```

- **경로 생성**: **Theta\* 알고리즘** (A\*보다 부드러운 경로)
- **동적 장애물 대응**: 셀 내 객체 정보 기반
  - 대형 몬스터 → 나무 상자 **파괴하고 이동**
  - 소형 몬스터 → 장애물 **우회**
- **충돌/밀어내기**: 캡슐 컴포넌트 오버랩 검사
  - 우선순위: 스킬 사용 중 > 큰 체형 > 빠른 속도
  - 우선순위 낮은 몬스터가 밀려남 → 이동 정체 방지

### AIFormation 시스템
- `GameDesign/System/AIFormation.uasset` 에셋과 연계
- 복수 몬스터의 대형/진형 관리

## AI 설계 패턴

### 에셋 분석 기반
1. **몬스터 타입별 분화**: Bot(기계), Skull(해골), Clriket(크리켓) 등 타입 내 변형 (A/B/C/Elite)
2. **보스 페이즈 분리**: 페이즈별 별도 AI 에셋 (ElderPhase1, ElderPhase2)
3. **영역별 변형**: 같은 몬스터라도 지역별 AI 변형 (Beach, Wasteland, EidosIX)
4. **콜라보 변형**: `_Nikke_AI` 접미사 — 니케 콜라보 DLC용 AI
5. **NPC→적 전환**: Tachy(타키)가 NPC AI와 Monster AI 모두 존재
6. **더미 AI**: 개발/테스트용 Dummy AI 에셋 (DummyElderPhase2, DummyScarlet)
7. **역할 기반 분류**: Attacker/Defense/Range/Supporter — 전투 역할 명확 분리

### 언리얼 페스트 발표 기반 (시프트업 공식)
8. **셀 기반 포지셔닝**: EQS 대신 55×55 커스텀 그리드 → 실시간 장애물/충돌 처리
9. **Theta\* 경로 탐색**: NavMesh 기반이 아닌 셀 기반 부드러운 경로 생성
10. **체형별 환경 상호작용**: 대형=파괴, 소형=우회 → 몬스터 개성 강화
11. **우선순위 밀어내기**: 스킬>체형>속도 기반 충돌 해결 → 자연스러운 군집 이동
