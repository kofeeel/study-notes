## 플레이어 캐릭터 — EVE (8,405 파일)

### 코스튬 시스템
- 네이밍: `CH_P_EVE_{번호}` (01~30+)
- 각 코스튬 폴더 구성:
  - `Textures/` — Diffuse(A), Normal(N), ORM(AO/Roughness/Metallic), DMSE, ORSS
  - `Materials/` — MaterialInstance
  - `Mesh/` — SkeletalMesh
- TypeA / TypeB 변형 (의상 바리에이션)

### 악세서리 시스템
- 폴더: `PC/00_ACC/`
- 카테고리:
  - `ACC_EAR_` (귀걸이) — 01~17+
  - `ACC_HAIR_` (헤어) — 별도 SkeletalMesh
- 각 악세서리 구성:
  - `*M.uasset` — SkeletalMesh
  - `*M_AnimBP.uasset` — AnimBP (KawaiiPhysics 기반 물리)
  - `*M_PhysicsAsset.uasset` — PhysicsAsset
  - `*M_Skeleton.uasset` — Skeleton
  - `*_Anim.uasset` — 기본 애니메이션
  - `*M_TypeB.uasset` — TypeB 변형 메시

### 애니메이션 구조 (PC)
- `CH_P_EVE_01/Animation/` — 메인 전투/이동 애니메이션
- `event/` 하위에 챕터별 이벤트 애니메이션:
  - `B07/` (SpaceElevator), `C05/` (Nest), `E04/` (Xion)
  - `F02/` (지역2), `G03/` (Prologue)
- BlendSpace 사용: `IdleRun_BS_Battle`, `IdleRun_BS_Peaceful`, `Airborne_BS`

## 몬스터 캐릭터 (7,326 파일)

### 네이밍 규칙
- `CH_M_{타입코드}_{번호}` (예: CH_M_NA_01, CH_M_NA_02)
- `NA` = Naevi (자연형), 기타 코드는 계열별

### 몬스터 에셋 구조 (CH_M_NA_02 예시)
```
CH_M_NA_02/
├── Animation/
│   ├── Additive/         — 방향/조준 보정 (LookAt_L, LookAt_R)
│   ├── BlendSpace/       — 상태별 블렌드 (Idle, Battle, Airborne, Groggy, Dead)
│   ├── Hit_*             — 피격 애니메이션
│   └── Mon_*             — 공격/스킬 애니메이션
├── Blueprints/
│   ├── *_AnimBP.uasset   — Animation Blueprint
│   └── *_BluePrint.uasset — Character Blueprint
├── StaticMesh/
│   ├── MA/               — Material Assets
│   └── Texture/          — 텍스처 (D, N, ORM)
├── Projectile/           — 투사체 (원거리 몬스터)
├── *_Skeleton.uasset     — 스켈레톤
└── *_PhysicsAsset.uasset — 물리 에셋
```

### 몬스터 애니메이션 상태
- `Idle`, `Run`, `Battle`, `Airborne`, `Groggy`, `Dead`, `Down`, `GetUp`
- `Link_Dead` — 연결 사망 (부위 파괴?)
- `LockOn` — 타겟 추적
- `Hit_Sword_Beta_Absorption` — 검 베타 스킬 흡수 피격

## KawaiiPhysics 활용
- 악세서리(귀걸이, 머리카락)에 KawaiiPhysics 플러그인 적용
- 각 악세서리에 독립 AnimBP + PhysicsAsset
- 실시간 물리 시뮬레이션으로 자연스러운 흔들림 표현

## 설계 패턴
1. **코스튬 = 독립 에셋 폴더**: 각 코스튬이 텍스처+머티리얼+메시 완전 세트
2. **악세서리 = 분리된 SkeletalMesh**: 메인 캐릭터에 Attach하는 방식
3. **TypeA/TypeB 변형**: 같은 코스튬의 노출도/스타일 변형
4. **챕터별 이벤트 애니메이션**: 스토리 챕터마다 전용 애니메이션 세트
5. **PBR 텍스처 파이프라인**: Diffuse(D), Normal(N), ORM, DMSE 일관된 채널 패킹
