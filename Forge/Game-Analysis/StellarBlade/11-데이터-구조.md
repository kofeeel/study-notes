# 11. 데이터 구조

## 데이터 관리 방식
스텔라블레이드는 낙원과 달리 **DA_/DT_ 접두사 컨벤션을 사용하지 않음**.
데이터를 폴더 구조와 시스템별 에셋으로 관리하는 방식.

## GameDesign 데이터 (8,089 파일)
| 폴더 | 수량 | 데이터 유형 |
|------|-----:|-----------|

| Combat | 281 | 전투 데이터 (BehaviorTree, MoveCurve) |
| System | 100 | 시스템 데이터 (Dialogue, Fishing, 등) |

## Local 데이터 (213 파일)
- `Local/Data/` — 153파일: 로컬 저장 데이터
- `Local/Default/` — 30파일: 기본값 데이터

## Lua 스크립팅 (slua_unreal)
- **slua_unreal 플러그인** 존재 → 게임 로직을 Lua로 작성
- 이벤트, 퀘스트, UI 로직 등을 Lua 스크립트로 관리 추정
- Lua 스크립트는 .pak 내부에 포함되어 별도 접두사 없이 관리

## 설계 패턴
1. **폴더 기반 데이터 관리**: 접두사 대신 폴더 계층으로 데이터 분류
2. **Lua 데이터 주도**: 게임 로직/이벤트를 Lua 스크립트로 유연하게 관리
3. **대규모 로컬라이제이션**: 전체 에셋의 31%가 L10N → 글로벌 출시 대비
4. **ResourceCache**: 런타임 성능 최적화를 위한 리소스 사전 캐싱
5. **Definition 패턴**: UI 구성을 코드가 아닌 데이터 에셋으로 정의
