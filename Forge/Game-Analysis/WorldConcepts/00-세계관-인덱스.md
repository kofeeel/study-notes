# 세계관 컨셉 인덱스

3D 스타일리시 액션게임용 세계관 후보 6종.
톤: B급 감성 + 하이엔드 액션. 레퍼런스 DNA는 킬빌, 사무라이 참프루, 소울이터.

| # | 코드명 | 한줄 요약 | 레퍼런스 |
|---|--------|----------|----------|
| 1 | [[01-네온저승-고스트킬러]] | 귀신 퇴치 회사 말단이 형의 진실을 파헤치며 간부를 죽여 올라간다 | 주술회전 + 존윅 + 블리치 |
| 2 | [[02-블랙메이드-잔혹한미식]] | 식재료로 사육된 소녀가 탈출해서 자기를 먹으려던 가문을 역으로 서빙한다 | 약속의 네버랜드 + 흑집사 + 킬빌 |
| 3 | [[03-하이퍼붓다]] | 디지털 극락의 보안 프로그램이 자아를 얻고 시스템을 부수러 간다 | 매트릭스 + SAO + 공각기동대 |
| 4 | [[04-데드라인카니발]] | 혀 잘린 광대가 공포 퍼포먼스로 서커스 도시의 지배층을 끌어내린다 | 오징어게임 + 헝거게임 + 데드맨원더랜드 |
| 5 | [[05-슬로터하우스락]] | 누명 쓴 기타리스트가 동료를 구하기 위해 차트 10위→1위를 라이브 배틀로 올라간다 | 스콧필그림 + NMH + 테너시어스D |
| 6 | [[06-언더테이커스]] | 마지막 장례지도사가 열면 안 되는 관을 지키며 장례 기업과 싸운다 | 얼터드카본 + 엘리시움 + 뱀파이어헌터D |
