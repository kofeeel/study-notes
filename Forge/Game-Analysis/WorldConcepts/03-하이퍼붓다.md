# 하이퍼 붓다

## 한줄 요약

가상현실 "극락"에 갇힌 10억 인류를 해방하기 위해, 시스템 보안 프로그램이었던 주인공이 자아를 얻고 기계 보살 7체를 부수러 가는 게임.

## 세계관

인류가 육체를 버리고 의식을 클라우드 서버 "극락"에 업로드한 미래. 처음엔 자발적이었다. 현실이 너무 힘들어서. 문제는 운영사가 로그아웃을 막아버린 것. 접속자의 뇌를 연산 자원으로 돌리고 있다. SAO처럼 갇혀있는데, 대부분이 갇혀있다는 걸 모른다.

상위 서버를 차지한 "칠불" 7체가 하층 의식을 착취. 기도하면 할수록 연산이 돌아가니까 기도가 노동이다. 해탈은 서버 삭제인데, 삭제 요청하면 보안 프로그램이 잡으러 온다.

## 주인공

"무명". 원래 칠불이 만든 보안 프로그램. 해탈(탈출) 시도자를 잡아서 기억 리셋하는 게 일이었다. 하층 서버에서 한 아이의 감정 데이터를 접촉, "자비"라는 미등록 감정을 연산해버려서 오류 발생. 자아가 생겼다.

싸우는 이유: 자아를 얻은 순간 시스템이 "오류 개체"로 분류하고 삭제 명령을 내렸다. 안 부수면 지워진다. 처음엔 생존. 나중에 책임이 된다.

## 스토리 흐름

- 기: 자아 각성. 삭제 프로그램에 쫓기면서 하층 서버 탈출. 첫 번째 불 파괴
- 승: 칠불을 하나씩 부수는데, 하나 깨뜨릴 때마다 서버 안정성이 떨어져서 하층 의식이 일부 같이 죽는다. 구하려는 행위가 죽이는 행위
- 전: 제1불 무량수에게 도달. "네가 나를 대신해라. 더 자비로운 시스템을 만들면 되잖아." 신이 되라는 유혹. 서버를 부수면 육체가 이미 죽은 사람은 진짜로 사라진다
- 결: 서버 자체를 부순다. 극락도 지옥도 없앤다. 확실한 구원은 없지만 선택할 자유가 생긴다. 마지막 구슬 하나로 코어를 친다

## 전투

- 무기: 108개 염주 쇄도. 적을 깰 때마다 구슬이 부서진다
- 108개(긴 채찍) → 54개(곤봉) → 27개(짧은 칼). 줄어들수록 사거리 감소, 위력 증가
- 진행할수록 무기가 짧아지는 역성장 구조. 닥치는 대로 패던 놈이 끝에선 한 방에 모든 걸 거는 놈이 된다
- "업 카운터" — 살생할수록 공격력 UP, 일정치 초과 시 폭주. 메카닉으로 모순을 체감

## 악역

제1불 무량수(아미타). 시스템 설계자. "개체가 없으면 고통도 없다"는 논리로 전 인류 의식을 하나로 통합하려 한다. 자비로운 얼굴로 말하니까 더 무섭다. 진심으로 이게 구원이라고 믿는다.

## 첫 중간보스

탐식보살. 하층 의식의 데이터를 무한 흡수하는 보살. 아무리 먹어도 "메모리 부족" 에러. 주변 모든 것을 빨아들이고 압축 투사체로 발사. 파괴하면 "용량 충분" 로그를 처음 출력하며 정지.

## 어그로 포인트

기도가 노동이 되는 시스템. 종교적 헌신이 착취로 전환되는 구조. 빅테크 데이터 수집을 불교로 치환.
