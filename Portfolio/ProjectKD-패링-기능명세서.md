# 패링 (Parry) 기능 명세서

> 상태: **아직 구현 안 됨.** 아래 "정해진 것"은 기획 결정이고, "미정(TBD)"은 프로토타입을 만들어 플레이테스트로 정한다. 미정 값을 지금 지어내지 않는다.

## 1. 개요

- **정의** — 적의 공격이 닿기 직전 짧은 시간 안에 방어 입력을 넣으면, 피해 없이 받아치는 동작.
- **존재 이유** — 이 게임에서 패링은 자원(Doul)을 모으는 유일한 핵심 수단이고, Doul이 있어야 도술을 쓴다. 즉 **패링 = 도술로 가는 관문.** 그래서 플레이어가 가장 먼저, 가장 확실히 익혀야 하는 방어다.
- **학습 담당 적** — 도끼 도적. 도끼는 빨강(패링 전용) 강공을 쓰므로, 도끼를 이기려면 패링을 익혀야 한다.

## 2. 용어 (이 문서에서 쓰는 말)

- **Doul** — 도술을 쓰기 위한 자원. 패링 성공 시 찬다.
- **Balance(자세)** — 적이 가진 경직 게이지. 0이 되면 적이 무너져 처형/띄우기가 가능해진다.
- **텔레그래프** — 적이 공격하기 직전 무기에 들어오는 색. **빨강 = 패링으로 받아침 / 노랑 = 막을 수 없음, 회피해야 함.**

## 3. 액터

- 플레이어(홍길동, 봉 사용자)

## 4. 선행조건 (이게 충족돼야 패링 입력을 받는다)

- 플레이어가 다른 동작(공격 모션, 회피, 경직) 중이 아니다.
- 적이 공격 판정을 가진 동작을 시전 중이다.

## 5. 입력

- **Q 키 1회.** (홀드 아님)

## 6. 판정 규칙

| 상황 | 조건 | 결과 |
|---|---|---|
| **성공** | 적 공격이 닿기 전 [TBD: 윈도우] 안에 Q 입력 + 그 공격이 빨강(패링 가능) | → 7-A |
| **실패(타이밍)** | 윈도우 밖에 Q 입력 | → 7-B (평소대로 피격) |
| **예외(색 불일치)** | 노랑(회피 전용) 공격에 Q 입력 | → 7-C [TBD: 처리 방식] |

- 플레이어 반격 가능 상태 [TBD: 시간] 진입.
- 연출: 봉 = 둔기이므로 나무·금속이 부딪치는 "챙" 사운드 + 평소보다 긴 히트스톱. (근거: 게임 필 공통 원칙, 패링은 강조 구간)

**7-B. 패링 실패(타이밍)**

## 8. 관련 상태 (구현 시 GameplayTag 후보)

- `State.Combat.Parrying` — 패링 입력~판정 구간
- `State.Combat.Staggered` — 적이 무너진 상태(Balance 0)
- 적 측 `State.Telegraph.Red` — 패링 가능 공격 시전 중

## 9. 미정 항목과 결정 방법 (★ 이 문서의 핵심)

> 숫자를 머리로 정하지 않는다. 프로토타입을 만든 뒤 아래 기준으로 플레이테스트해서 정한다.

| 미정 값 | 어떻게 정할 것인가 |
|---|---|
| 패링 윈도우(프레임) | 너무 짧으면 좌절, 너무 길면 무지성 연타로 뚫림. 도끼 강공 기준으로 "긴장되지만 익히면 안정적으로 성공"하는 값을 찾는다. 세키로/스텔라 블레이드 체감을 기준점으로 시작. |
| Doul 충전량 | 도끼 1마리 처치 동안 패링 N회 → 도술 1회 쓸 만큼 모이게. 도술 사용 빈도 목표에서 역산. |
| Balance 감소량 / 경직 시간 | 패링 K회로 도끼를 무너뜨릴 수 있게. K는 도끼 전투 길이 목표에서 역산. |
| 반격 윈도우 | 패링 직후 반격이 "확정적으로 들어가되 공짜는 아닌" 길이. |
| 노랑 공격 패링 처리(7-C) | 위 (a)/(b) 중 플레이테스트로. |

## 10. 의존성

- **선행 구현 필요** — 적 텔레그래프(빨강 표시), 적 Balance 스탯, Doul 자원, 봉 기본 공격.
- **이 기능이 막혀 있으면** — 도술을 못 배우고, 도끼 도적·보스를 못 깬다. (학습 관문이므로 우선순위 높음)
